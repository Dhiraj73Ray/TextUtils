# 📝 TextUtils - Django Text Analyzer (Archived)

A Django web app that analyzes and manipulates text. Built while learning Django fundamentals.

## Features
- Remove punctuation
- Convert to uppercase
- Remove newlines
- Remove extra spaces
- Count characters

## Tech Stack
- Django 4.2
- Bootstrap 5
- SQLite (default)

## Status
📦 **Archived** - This was a learning project from 2024. Not maintained.
For professional Django work, see [other repos].

## How to Run
```bash
pip install django==4.2
python manage.py runserver
```
